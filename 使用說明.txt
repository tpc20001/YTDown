AndroidKit 開發用空架子（V0.1.01，外殼 S1）

這是什麼：
  一個「什麼功能都還沒有」的 Android App 骨架（跟電腦版的 AppKit 一樣的概念）。不用再重調的基礎功能都已經放進來了：
  左邊選單、右上 📊效能／🖥後台／🌙縮到背景／🏠封面、下方深色／淺色＋介面大小、
  後台總控制（暫停／繼續／立刻停／先後順序／太熱、電量低、太吃 CPU 自動讓路／⚖ 讓路名單）、
  設定（含 📡 遠端網頁：電腦瀏覽器就能看、能控制，可配 Tailscale）、
  版本與更新（熱更新，App 不用重裝；新版開不起來自動換回）、☁ GitHub 雲端打包＋自動更新、
  LOG、實驗工作區、閃退自動重開、分屏／小窗自動縮放、只能開一個。

要開發新程式時：
  1. 把這整包 zip 丟給 AI，說「用這個空架子做一個 ○○○ App，名稱叫 ○○，更新包前綴 ○○」。
     AI 會先讀 AI_開發指南.md（你的規則、更新包規則、架構、怎麼加功能、GitHub 雲端更新），
     需要的話再看 AI_功能庫.md（讓路、背景跑很久、檔案安全…這些的做法）。不用再教一次。
  2. 第一次安裝：AI 給你改好的整包 → 解壓縮 → 手機用 USB 接電腦（開 USB 偵錯）→ 點兩下 BUILD_AND_INSTALL.bat
     （自動下載 Java、Android SDK、做簽章鑰匙、打包 APK、裝到手機；第一次大約 15～30 分鐘）。
     手機沒接的話，APK 會放在桌面的資料夾，傳到手機點一下安裝。
     ★ keystore 資料夾（簽章鑰匙）一定要留著，桌面資料夾裡也有一份備份。換了鑰匙，手機就要先移除舊版才能裝。
  3. 之後每一版，二選一：
     A．手動：AI 給你「前綴_V0.1.02.zip」這種更新包 → 傳到手機 → App 的 ⟳ 版本與更新 → 選更新包 → ⚡ 熱更新。
        也可以在檔案管理、LINE 裡對 zip 按「分享」→ 選這個 App；或在電腦的 📡 遠端網頁 → 更新 → 上傳。
     B．☁ 雲端（推薦，設定一次就好）：App 裡 ⚙ 設定 → ☁ 雲端更新 → 🧭 設定精靈，照著一步一步做
        （註冊 GitHub、建 repo、點 MAKE_GITHUB_KEY.bat 放簽章鑰匙，大約 15 分鐘，有給初學者的說明）。
        之後 AI 改好推到 GitHub，雲端自動打包，每支手機的 App 自己跳「☁ 有新版」→ 按 ⬇ 更新。
        別支手機第一次安裝：GitHub 的 Releases 頁下載 .apk → 安裝。

  只改畫面的版本：熱更新就好，不用重裝。
  改到外殼的版本（AI 會說）：雲端會做新的 APK，App 跳「外殼有新版」→ 按更新 → 系統安裝畫面按「更新」。
    沒有用雲端的話，重新點一次 BUILD_AND_INSTALL.bat。

更新包規則（AI_開發指南.md 第 5 節有完整的）：
  檔名 <前綴>_V0.1.02.zip；版本最後一段兩位數，0.1.99 的下一版是 0.2.01。
  只會換畫面；設定、資料庫、背景工作清單、LOG 永遠不動。

直接試這個空架子：點 BUILD_AND_INSTALL.bat → 手機上會多一個 AndroidKit。
  首頁按「＋ 排 5 個示範背景工作」，到 🖥 後台 看暫停／繼續／立刻停／自動讓路；
  ⚙ 設定 → 📡 遠端網頁 設 PIN、打開，電腦瀏覽器打上面的網址就能看。
  預設遠端網頁埠 8571（電腦版 AppKit 是 8561，不會撞）。
  在電腦瀏覽器直接開 app\src\main\assets\www\index.html 也能先看畫面（手機才有的功能不會動）。
